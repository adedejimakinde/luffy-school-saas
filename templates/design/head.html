{% load static %}{% comment %} The design every page shares, linked before the page's own stylesheet so the page's rules can narrow it. Included, not copied: one line in each page template and one place to change. `static/web/design.css` says what is in it. The regular weight is preloaded because it is the text of every page; the bold one is left to the stylesheet to ask for, since a page can draw without it. `crossorigin` is required on a font preload even from our own host — without it the browser fetches the file twice. Every page that draws from here asks search engines to leave it alone, unless its view says it is the public site's (`indexable`, which only `website.views` sets). Default deny, so a new staff page cannot be indexed by forgetting: `website/crawlers.py` sends the same as a header on every host but the site's. The icons are the header's mark (`scripts/favicons.py`), at fixed addresses at the root of whichever host drew the page (`WHITENOISE_ROOT` in settings.py): the public site, the portal and every school. {% endcomment %} {% if not indexable %} {% endif %}
