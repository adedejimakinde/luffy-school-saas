{% comment %} Exam slips for one class, or one student, one slip each. Rendered by `cbt.pdf.render_slips()` in the request that mints the PINs, and stored nowhere: this document is the only place the raw PINs ever exist (`cbt.pins`, `docs/cbt.md`). No marks and no questions. A slip lets a student sign in to sit a test this term, behind the test code their teacher reads out when the test starts. Eight slips to an A4 page, each a box that does not break across pages, so the school can cut along the borders. The same layout as the result checker's slips. {% endcomment %} Exam slips: {{ school_name }} {% for slip in slips %}
