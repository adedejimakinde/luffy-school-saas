A `{#` comment is single-line only: spanning lines it is not a comment at all and every word renders on the page. This project has shipped that bug before. ## The one frame every error page wears 404, 500, 403 and the CSRF refusal were each Django's own page, or in the 403's case a page of its own that shared nothing: serif, black on white, no mark, no way out. They extend this file, so they look like Classnode and each carries a link back to `/`, which is the right place on every host: the portal sends it to the staff sign-in, a school's host to the school's own page, and the bare domain to the homepage. A link to `/` needs no query, which matters because the 500 page is rendered by Django with no context at all, while the database may be the thing that is down. ## No stylesheet, no modules, no `{% load static %}` Deliberately, and the reason the 403 page already gave: this is the page that has to render when something is already wrong, and every asset it depended on would be another thing that can be missing at exactly that moment. The styling below is inline and small enough to read. It carries its own copy of the few values it uses from `static/web/design.css`, the only pages that do, and `tests/test_design.py` holds every one of them to that file's palette. No web font: the system stack is design.css's own fallback. The mark is the shell's `i-brand-mark` written out, because a `` sprite is a template include too many here. {% endcomment %}
