2. **What `GET .../pdf/` does with no file yet** — a 202 that distinguishes

3. **One PR or two** — way in, then way out.

### Settled already; do not re-derive

- Enqueue from `services.release()`'s `freeze_the_card()` via
  `transaction.on_commit` — **never a bare `.delay()`**: a worker on another
  connection finds no card under READ COMMITTED and writes a failure row for a
  card that is about to be fine.
- The enqueue **must not fail the release**. `on_commit` runs after the commit,
  so an exception there hands the principal a 500 for cards that already went
  home. Catch per card, log.
- The enqueuer wants **`(schema_name, card_id)`**, not prefetched cards — the
  worker re-reads in its own transaction, which is what makes it idempotent.
- **Keep task 8's `DISTINCT ON (student_membership_id) … ORDER BY version DESC`**
  or a 45-child class enqueues 46 jobs and sends a superseded version home.
- `cards.cards_on()` has **no caller anywhere**; its docstring claims task 7's
  job "walks a whole class" when it renders one card per job. Fix that docstring
  when the enqueuer lands — the walk is the missing piece.

## 4. Working notes worth keeping

- **Postgres is at host `db`**, not localhost. `docker` is not installed.
  `/usr/bin/time` is not installed — time with bash `$SECONDS`.
- **Two test processes cannot run at once** — they collide on `test_luffy_db`.
  Serialise in one script, and kill stale backends between runs (#61).
- **Watch a long run on the script's `^EXIT=` line, not on `ERROR`.** A monitor
  grepping `ERROR` fires on a *passing* run, because tests deliberately provoke
  a Celery `RuntimeError('no fonts')` and log it. Cost a false alarm today.
