## Traps this project keeps re-finding

- `ReleasedCardPdf.card` is `PROTECT` and now exists for **every** card, so any
  raw `DELETE FROM results_releasedcard` in test staging must clear the marker
  rows first.
- `connected_to()` does not nest — a helper that opens its own block must never
  be called from inside another one.
- A binary 200 in django-ninja is declared `response={200: None, …}`; ninja hands
  a raw `HttpResponse` back untouched. The `return 202, Body` tuple is deprecated
  in 1.6.3 in favour of `Status(...)`, but every endpoint here uses the tuple and
  the new route matches the house style deliberately.
- A refusal of **state** over HTTP is a **423**, not a 409 and not a 403.
