CBT: mockups

Phase 1, static HTML only, no feature code. Each page links the real design.css, and cbt.css holds the new parts, tokens only. Open at 375 px and 1280 px. Screenshots of each are in shots/. The design note is docs/cbt.md. Every question shown is written for these mockups; none is taken from JAMB, WAEC or NECO.

Teacher: questions and tests

  • 1. Question bank
    By subject and class level, only the teacher's own. Filters, answer key, options A to D or A to E, used in how many tests.
  • 1b. Question bank with a licensed provider turned on
    How it would look if the platform turned one on: read-only, tagged with the provider, Copy to my bank, and the plain message when the provider is down. Off by default.
  • 2. Add or edit a question
    Stem, optional image, 4 or 5 options, one correct, optional explanation, and a shuffled preview.
  • 3. Set a test
    Title, subject, the teacher's own classes, kind of test, questions drawn by topic, the window and time.
  • 4a. Settings: class test
    Timing, late-answer window, shuffling, one attempt, sign-in, release, who can see it.
  • 4b. Settings: UTME practice
    English plus three, per-subject counts and total time as settings (defaults from JAMB's 2026 manual), each student's subjects, the CBT centre screen.
  • 4c. Settings: WAEC objectives
    One subject per paper, its own timer, A to D, counts and minutes per subject as settings.

Student: sitting the test

  • 5a. Sign in to sit
    Test code, admission number, exam PIN. The recommended option; see the note for the others.
  • 5b. Is this you?
    Checked before the clock starts.
  • 6a. Test screen: normal
    Subject tabs, question, options, Previous, Flag, Next, the number grid, calculator, keys A to D, N, P, S.
  • 6b. Flagged, calculator open
  • 6c. Network lost
    Keeps going, answers kept on the computer, sent when it is back.
  • 6d. Time almost up
  • 6e. Submitted
    No score until release; the local copy is cleared.

Teacher: after the test

  • 7. Results and item analysis
    Hardest questions first, who chose what, a "check the key" warning, the score spread, and each student's start, drop-off and submit times.
  • 8a. Send to CA
    Pick the column, scale, keep or replace existing marks, preview, a locked class refused.
  • 8b. Send to CA: confirm

  • 9b. Parent: their child's released scores
