# The report card page's own assets — its ES modules and stylesheets — are
# served by the application process, because this platform has no CDN and no
# web server in front of Django. WhiteNoise is what makes that defensible
# rather than a development shortcut: hashed filenames, pre-compressed bytes and
# a far-future cache header, from one process, with no extra moving part to
# deploy. settings.py says why the hashing is off under DEBUG.
whitenoise>=6.6

# Background work. A report card PDF is minutes of rendering for a class of
# forty-five, which is not a thing to do inside a request: Celery moves it off
# the web process, Redis is the broker it hands the job to (settings.py says why
# there is no result backend), and WeasyPrint is what turns the card's HTML into
# the file a parent keeps. See docs/background.md.
#
# WeasyPrint is not pure Python — its text layout is Pango's, so it needs Pango,
# HarfBuzz and a font family from the operating system. It installs from a wheel
# perfectly happily without them and fails at the first import. Both places that
# build an environment for this project install them explicitly:
# .devcontainer/Dockerfile and .github/workflows/tests.yml.
celery>=5.4
redis>=5.0
weasyprint>=62

# What serves the application in production (`deploy/compose.yml`). Sync
# workers: every request is short except the bulk import, and a process per
# worker keeps a connection per request — the only topology issue #115 allows.
gunicorn>=22.0
